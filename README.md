## 1.주제 선정 배경 및 필요성

1. 반려동물 양육가구 증가에 따른 사회적 / 일상적 정보 요구 증가
    - 반려동물 양육의 대중화: 농림축산식품부 발표 통계에 따르면 대한민국 반려동물 양육가구 비율은 2%에 달해 '이웃집 3곳 중 1곳'이 반려동물과 함께 살아가고 있습니다. 세부적으로는 반려견을 기르는 비율이 80.5%로 압도적인 비중을 차지하여, 반려견과 함께 이동하고 활동하는 생활 양식이 보편화되었습니다.
    - 출입 가능 업소 정보의 불확실성과 파편화: 반려동물 동반 외출 및 이용 수요는 지속적으로 증가하고 있으나, 실제 현장에서는 카페, 식당, 숙소 등의 동반 출입 가능 여부(실내/ 테라스/ 케이지 필수/ 무게 제한 등)가 방침 변경이나 허위 정보로 인해 명확히 안내되지 않는 문제가 빈번합니다. 이에 따라 블로그, SNS, 지도 앱 등에 흩어진 실제 방문자 리뷰 데이터를 크롤링하여 정확한 동반 가능 정보를 직관적으로 제공하는 서비스 구축이 필요합니다.
2. 높은 동물병원 이용률 및 의료비 부담 완화를 위한 1차 AI 헬스케어의 필요성
    - 높은 의료 서비스 의존도: 조사 결과 최근 1년 이내 반려동물 관련 서비스 이용 경험 중 동물병원이 1%로 가장 높은 비율을 기록했습니다. 이는 반려인 대다수가 반려동물의 건강관리를 최우선 과제로 인식하고 있음을 보여줍니다.
    - 경제적/ 시간적 부담과 정보 공백: 조사결과 반려견 1마리당 월 평균 양육비는 약 13만 5천 원에 달하며, 이중 정기 진료 및 사고·질병 치료를 포함한 병원비 지출 비중이 상당합니다. 비싼 의료비나 야간 시간대 등 즉시 병원을 방문하기 애매한 상황에서, 반려인들은 불안감을 느끼거나 잘못된 민간요법에 의존할 위험이 있습니다.
    - LMM(Large Multimodal Model) 앙상블 기단 초동 상담 요구: 이미지(사진/ 영상)와 텍스트를 종합적으로 이해하는 멀티모달 AI 기술을 활용하여, 여러 AI 모델의 의견을 종합해 분석해주는 서비스가 필요합니다. 이는 응급성 판단 및 현 상태에 대한 다각성 조언을 제공하여, 병원 방문 필요성을 사전에 검토하고 의료비 부담 및 비효율을 완화하는 데 큰 기여할 수 있습니다.

## 2.유사 제품 분석 및 차별성

✔️‘기다려’앱

‘기다려’는 카페, 식당, 숙박, 관광지, 캠핑장 등 반려견과 함께 방문할 수 있는 장소를 검색할 수 있는 서비스이다. 강아지 크기별 동반 정책, 실제 방문자의 후기, 지도 기반 주변 장소 검색 등의 기능을 제공한다. 이외에도 산책로 공유, 산책 챌린지, 반려견 SNS 및 모임, 반려견 용품 물물교환 등 반려견 보호자를 위한 다양한 기능을 제공하고 있다. 본 프로젝트와의 차별점은 단순히 반려견 동반 가능 여부를 제공하는 것에서 나아가, 장소와 관련된 리뷰를 주기적으로 수집하고 AI를 활용하여 리뷰 내용을 분석한다는 점이다. 이를 통해 ‘실내 동반 가능’, ‘테라스만 이용 가능’, ‘유모차 또는 이동가방 필요’, ‘목줄 착용 필수’, ‘대형견 가능’ 등 실제 방문 시 필요한 조건을 카테고리화하여 제공한다. 또한 새로운 리뷰를 주기적으로 재수집하여 변경된 이용 조건을 반영함으로써 장소 정보의 최신성을 높이는 것을 목표로 한다. 추가적으로 사용자의 위치와 반려견 동반 장소 및 산책 장소를 활용하여 단순히 하나의 장소를 추천하는 것이 아니라 산책로 → 반려견 동반 카페 → 식당 등 여러 장소를 연결한 반려견 데이트 코스를 추천한다는 점에서도 차별성을 가진다.

✔️‘Pawmory’앱

‘Pawmory’는 반려동물의 일상을 기록하면 AI가 기록 내용을 분석하여 제목 생성, 태그 생성, 내용 요약, 일상·건강·활동 등의 카테고리 자동 분류와 AI 인사이트를 제공하는 반려동물 기록 서비스이다. 또한 기록된 데이터를 PDF 형태로 내보낼 수 있어 반려동물의 일상을 보관하고 관리할 수 있다. 본 프로젝트와의 차별점은 사용자가 직접 일기를 작성하고 이를 AI가 정리하는 방식에서 나아가, LLM과의 자연스러운 대화 자체를 반려견의 건강 및 생활 기록으로 활용한다는 점이다. 누적된 대화 내용을 기반으로 일정 기간 동안의 식사, 산책, 배변, 이상 증상, 행동 변화 등을 정리하고, 동물병원 방문 시 활용할 수 있도록 최근 한 달의 주요 건강 및 생활 변화를 1페이지 PDF 리포트로 생성한다. 따라서 단순한 일상 기록 및 PDF 저장보다 ‘대화 → 정보 추출 → 장기간 기록 → Multi-LLM 분석 → 병원용 요약 리포트’로 연결되는 건강관리 과정에 차별성을 둔다.

✔️‘펫핑’앱

‘펫핑’은 반려견의 건강한 생활 습관 형성에 초점을 둔 서비스로, GPS를 활용하여 산책 시간과 거리를 기록하고 식사량을 기록할 수 있다. 일주일 동안의 섭취 칼로리, 산책 횟수 및 거리 등의 데이터를 통계로 확인할 수 있으며, 지도에서 주변 반려견 동반 장소와 놀이터 등의 정보도 제공한다. 산책 미션을 수행하면 포인트를 지급하고 이를 반려견 용품 구매에 사용할 수 있는 리워드 기능도 제공한다. 본 프로젝트와의 차별점은 사용자가 각각의 건강 데이터를 직접 입력하고 통계로 확인하는 방식보다 대화형 AI를 건강 기록의 인터페이스로 활용한다는 점이다. 사용자가 별도의 기록 메뉴를 찾아 식사량이나 건강 상태를 일일이 입력하지 않아도 AI에게 일상적으로 이야기하면 필요한 정보를 자동으로 분류하여 기록할 수 있도록 한다. 또한 기록을 단순한 통계로 보여주는 데 그치지 않고 일정 기간의 데이터와 건강 상담 내용을 종합하여 변화나 반복되는 이상 상태를 정리하고 병원 방문에 활용할 수 있는 리포트를 제공하는 것을 목표로 한다. 산책 기능에서도 단순히 사용자가 걸은 경로를 기록하는 것보다 반려견과 함께 방문할 수 있는 장소를 조합하여 하나의 데이트 코스를 추천하는 기능에 초점을 둔다.

✔️‘멍냥보감’앱

‘멍냥보감’은 반려견과 반려묘의 건강, 육아, 여행 정보를 종합적으로 제공하는 서비스이다. 반려동물 동반 장소 검색, 나들이 장소 저장, 산책 기록 및 통계, 몸무게 예측, 건강 관련 정보, 사료 급여량 계산 등의 다양한 기능을 제공한다. 본 프로젝트와의 차별점은 여러 반려생활 정보를 제공하는 것보다 사용자와 반려견의 개별 데이터를 기반으로 AI가 지속적으로 정보를 축적하고 활용하는 개인화된 서비스를 지향한다는 점이다. 또한 반려동물 동반 장소를 단순히 검색하는 기능에서 나아가 리뷰의 자연어 내용을 분석하여 실제 이용 조건을 구조화하고, 해당 정보를 이용하여 반려견에게 적합한 장소와 데이트 코스를 추천한다는 차이가 있다.

**프로젝트의 핵심 차별성**

기존 반려견 관련 앱들은 크게 동반 장소 검색, 산책 기록, 건강·일상 기록, 커뮤니티 및 용품 거래 등의 기능을 각각 제공하고 있다.

본 프로젝트는 이러한 기능을 단순히 하나의 앱에 모으는 것보다 AI를 활용하여 기존 데이터를 자동으로 분석하고 개인화하는 것을 핵심 차별점으로 한다.

장소 분야에서는리뷰 수집 → 리뷰 AI 분석 → 동반 조건 자동 추출 → 카테고리화 → 정보 최신화 → 반려견 맞춤 장소 및 데이트 코스 추천

의 과정을 구현한다.

건강 분야에서는사용자와 AI의 자연어 대화 → 식사·산책·배변·증상 등 정보 자동 추출 → 장기간 데이터 축적 → 여러 LLM의 분석 결과 비교·취합 → 건강 상태 및 변화 요약 → 동물병원용 PDF 리포트 생성

의 과정을 구현한다.

따라서 본 프로젝트의 핵심은 단순한 ‘반려견 종합 앱’이 아니라 리뷰와 사용자의 자연어 데이터를 AI가 분석하여 반려견의 외출과 건강관리에 실질적으로 활용할 수 있는 정보로 변환하는 AI 기반 반려견 생활 통합 플랫폼이라는 점에 있다.

## 핵심 기능을 포함한 개발 목표

Spring Boot 기반 REST API 서버를 구축하여 회원, 반려견 기록, 지도, AI 챗 각 기능의 데이터를 처리 전담하는 백엔드 시스템 구현을 목표로 함

회원가입 시 반려견 프로필을 함께 등록하고, Spring Security 기반 인증을 통해 회원 관리 기능 구현

간식 및 먹이 기록과 병원 기록을 목적에 맞게 분리 저장하고, 날짜별/카테고리별 조회가 가능한 API 개발

조회한 기록 데이터를 사용자가 선택한 카테고리 기준으로 PDF 문서화하는 기능 구현

반려동물 출입 가능 장소 데이터를 관리하고, 사용자의 수정 요청을 관리자가 확인 및 승인할 수 있는 워크플로우를 API로 제공

복수의 무료 LLM API를 연동하여 교차검증된 응답을 사용자에게 제공하는 AI책 기능의 서버 로직 구현

계정당 반려견 1마리 구조로 우선 개발하되, 추후 다견 지원으로 확장 가능한 데이터 구조 설계를 목표로함

· React와 TypeScript를 기반으로 회원가입·로그인, 반려견 프로필 등록, 생활·병원 기록을 관리하는 사용자 화면 구현을 목표로 함.

· Tailwind CSS로 PC와 스마트폰 화면 크기에 맞는 디자인을 적용하고, React Router로 회원·기록·장소·채팅 화면 간 이동 기능 구현.

· Axios로 백엔드 서버와 연결하여 기록의 입력 및 날짜별·카테고리별 조회, 장소 정보 확인, 이용 조건 수정 요청 및 관리자 승인 화면 구현.

· React로 AI 채팅 화면을 구성하고 Axios로 질문과 답변을 주고받으며, 대화에서 정리된 건강 기록을 확인하고 서버에서 생성한 병원 방문용 PDF 리포트를 내려받는 기능 구현.

· Capacitor를 활용하여 개발한 웹 화면을 Android 앱으로 제작하고, Android Studio에서 앱 실행 및 화면 동작 확인.

## 사용 기술

### BE

프레임 워크: Spring Boot
데이터 베이스: Spring Data JPA, MySQL
인증/보안: Spring Security, JWT
동적 쿼리 처리: QueryDSL
외부 API 연동: 네이버 지동 API, 무료 LLM API
PDF 생성: Thymeleaf+Flying Saucer

### FE

화면 개발: React, TypeScript
화면 디자인: Tailwind CSS
화면 이동: React Router
서버 연결: Axios
Android 앱 제작: Capacitor, Android Studio
프로젝트 실행 및 빌드: Vite
